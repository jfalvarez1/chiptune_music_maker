Quick Workflow

1) Capture – Click START RECORDING, or load a WAV via Load WAV/Browse. Recording clears any imported file.
2) Choose Mode – Pick Melodic, Bass, Percussion, Rhythm, or Polyphonic.
3) Tune Settings – Adjust Sensitivity, Target BPM, pitch range, harmonize, or drum focus/kit.
4) Analyze – Click ANALYZE. Results appear in the piano-roll preview; auto-play if enabled.
5) Preview & Edit – Use PLAY PREVIEW. Right-click notes in the roll to override instruments.
6) Export – EXPORT TO .CTP with current BPM and quantization (16ths).

Detection Modes

Melodic (Pitch)

  • Tracks sung/played notes with YIN+FFT fusion, pitch median smoothing, and outlier rejection.
  • Pitch Range: All, Melody (>C3), Bass (<C4) filter to cut bleed.
  • Harmonize: Add octave, fifth, or smart 3rd (uses detected key when available).
  • Use when singing melodies, whistling, or playing a single lead line; best with clean input and moderate Sensitivity.

Bass Only

  • Low-frequency focused; longer window; adaptive envelope to avoid chopping sustained booms.
  • Fallback to MIDI 36 if pitch is undefined; good for “boom” beatbox basslines.

Percussion (Drums)

  • Classifies Kick/Snare/Hat with spectral centroid, dominant freq, zero-crossing, and band energy.
  • Drum Focus: filter to Kick, Snare, Hat, or Full Kit. Kit Mapping picks playback samples.
  • Writes debug to analysis_debug.txt after ANALYZE.

Rhythm (Onset)

  • Instrument-agnostic onset splitter using RMS + spectral flux; keeps hit lengths, no pitch.
  • Map the rhythm to any instrument (pluck, pad, bass) after detection; great for tapping/clapping patterns.

Polyphonic (Chords)

  • Captures top spectral peaks per window for simple triads/pads; adaptive gate to suppress noise.
  • Use for slow-moving pads or block chords; avoid very dense or percussive audio.

Key Controls

Input

  • Input Device: select mic/interface.
  • Load WAV/Browse: import mono WAV; Active Source shows path/rate.
  • START RECORDING: clears imported file, begins capture.

Analysis

  • Sensitivity: lower = more detections; raise to reject noise.
  • Target BPM: preview/export tempo; quantize to 16ths.
  • Harmonize: adds layers; Smart 3rd uses detected key.
  • Drum Focus/Kit: filter and pick samples for kick/snare/hat.

Preview

  • Target Instrument: global playback sound; override per-note via right-click in roll.
  • Advanced Preview: richer ADSR/effects for many synth presets.
  • Auto-Play: auto preview after analyze/apply effects.

Post-Processing

  • Harmonics: add up to 3 intervals (octave, 5th, 3rd).
  • Auto-Tune: snap to detected key scale.
  • Chain Melody: legato stitch between melodic notes.
  • COMMIT EDITS: save manual edits as new base before effects.

Tips & Troubleshooting

Too many fragments?

  • Raise Sensitivity slightly.
  • For Rhythm, separate hits with clearer gaps.
  • For Melodic, use Melody pitch range to ignore low rumble.

Missing notes?

  • Lower Sensitivity a bit.
  • Sing/beatbox closer to mic; avoid clipping.
  • Use Bass mode for low boom content.

Wrong drum class?

  • Check analysis_debug.txt after ANALYZE.
  • Set Drum Focus to the target (Kick/Snare/Hat) to filter.
  • Ensure WAV is mono or beatbox clearly separated.

Clicks or harsh tails?

  • Enable Advanced Preview for smoother envelopes.
  • Shorten very tiny notes (Chain Melody helps stitch).
Export note: .CTP export uses current BPM and 16th-note quantization. Set Target BPM before exporting for proper grid alignment.

Feature Highlights (Under the Hood)

  • Melodic: YIN + FFT fusion, median smoothing, outlier gating, adaptive RMS envelope, longer release for sustained tones.
  • Bass: onset gating tuned for low end; fallback to MIDI 36 when pitchless; retrigger protection to avoid chopping.
  • Percussion: centroid + dominant freq + ZCR + band energies; kick/hat tie-breakers; post-pass corrections; debug dump.
  • Rhythm: RMS + spectral flux onsets; preserves per-hit durations; instrument-agnostic mapping after detection.
  • Polyphonic: top spectral peaks with adaptive gate to avoid noise hits; good for slow-moving pads/triads.
